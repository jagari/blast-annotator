## ⚠️ 처음 실행할 때 (보안 경고)

**Mac**

2. 응용 프로그램 폴더에서 앱 실행 → "확인할 수 없음" 경고가 뜨면 **[완료]** (또는 [확인]) 클릭
3. **시스템 설정 → 개인정보 보호 및 보안** → 아래로 내려서 **[그래도 열기]** 클릭 → 암호 입력
4. 다시 앱을 실행하고 **[그래도 열기]** → 이후로는 그냥 실행됩니다

## 기능
- 서열 붙여넣기 / FASTA 파일 열기, 여러 서열을 한 번에 분석
- **빠른 검색**: 내 컴퓨터에서 서열당 1~2초, 인터넷 필요 없음 (UniProt Swiss-Prot 57만 단백질)
- **정밀 검색**: NCBI 서버의 전체 DB에서 검색 (인터넷 필요, 수 분~수십 분)
- 엑셀 결과: 추정 기능, 신뢰도(색 표시), 유래 생물, 유전자명, 일치도, E-value, 정보 링크

## 요구 사항
Windows 10/11 64비트 · macOS 12 이상 (Apple 칩). 다른 프로그램을 설치할 필요가 없습니다.
